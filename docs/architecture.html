Factory Inventory Management System

System architecture, tech stack, and data flow

Tech Stack

Frontend

  • Vue 3 — Composition API
  • Vue Router — SPA routing
  • Vite — dev server, port 3000
  • Axios — HTTP client
  • Custom SVG charts
  • i18n — English / Japanese

Backend

  • Python FastAPI
  • Pydantic — validation
  • Uvicorn — ASGI, port 8001
  • In-memory data store
  • CORS — open in dev

Data Layer

  • JSON files — server/data/
  • inventory.json
  • orders.json (350+ orders)
  • demand_forecasts.json
  • backlog_items.json
  • spending.json & transactions.json

System Architecture

Request Data Flow

FilterBar → useFilters() → View Component → api.js (Axios) → FastAPI Endpoint → apply_filters() → In-Memory Data → Pydantic → Computed Props
